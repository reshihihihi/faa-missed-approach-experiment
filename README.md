# FAA Missed Approach Extraction Experiment

## Overview

This project studies how to extract structured missed-approach information from FAA approach charts and compares several extraction pipelines on a 100-sample dataset.

The current formal experiment uses cycle `2604` and evaluates five methods against a CIFP-derived structured reference baseline.

## Method Paths

- `O`: CIFP reference baseline
- `A`: OCR + rules
- `B`: OCR + LLM
- `C`: image input + multi-question QA + JSON aggregation
- `D`: image input + single-pass full JSON extraction
- `E`: image input + questionnaire-constrained extraction before final JSON

## Dataset Notes

This repository is configured to keep lightweight dataset manifests and reports in Git while excluding large raw FAA source files and rendered chart images by default.

Included metadata files:

- `data/pilot_10/sample_manifest.json`
- `data/v2604_100/sample_manifest_100.json`
- `data/v2604_100/pairs_100.json`
- `data/v2604_100/selection_100.json`
- `data/v2604_100/candidate_pool.json`

Excluded by default:

- raw PDFs
- rendered chart images
- local CIFP source dumps
- preparation-stage intermediate files

## Environment

The codebase currently uses:

- Python
- `PaddleOCR` for OCR-based paths
- `anthropic` Python SDK for LLM-based paths
- `requests` for data download utilities

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Model Configuration

The LLM-based paths currently use:

- model: `claude-sonnet-4-6`
- SDK: Anthropic Python SDK
- temperature: `0`

Credentials are expected through environment variables such as:

- `ANTHROPIC_API_KEY`
- or `ANTHROPIC_AUTH_TOKEN`
- optional `ANTHROPIC_BASE_URL`

Do not commit real secrets to the repository.

## Formal 100-Sample Results

Current top-line metrics from `results/v2604_100/evaluation_report.md`:

| Path | Scalar F1 | Waypoint F1 |
|------|-----------|-------------|
| A | 0.629 | 0.437 |
| B | 0.588 | 0.647 |
| C | 0.705 | 0.691 |
| D | 0.684 | 0.677 |
| E | 0.687 | 0.688 |

Current summary:

- `C` is the best overall method in the formal 100-sample run.
- `D` and `E` are both strong image-direct baselines.
- OCR-based methods remain weaker overall than image-direct pipelines.

## Reproducibility Notes

Some scripts currently use local absolute paths such as `E:/experiment/...` and may need path cleanup if the project is moved to another machine or workspace.

For a public release, the recommended workflow is:

1. Clone the repository.
2. Recreate the environment from `requirements.txt`.
3. Download official FAA source data as needed.
4. Place large raw inputs outside Git-tracked directories or update local paths.
5. Run the corresponding path scripts.
6. Run `evaluate.py` and `error_analysis.py`.

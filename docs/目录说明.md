# 目录说明

当前项目按“预实验 / 正式实验 / 数据准备”进行整理。

## 顶层结构

- `data/`
  - `pilot_10/`：10 样本预实验数据
  - `v2604_100/`：100 样本正式实验数据
  - `preparation/`：样本筛选与数据准备阶段的中间产物
- `results/`
  - `pilot_10/`：10 样本预实验结果
  - `v2604_100/`：100 样本正式实验结果
- `prompts/`：各路径提示词
- `scripts/`：实验脚本
  - `debug/`：调试脚本
- `docs/`：方案文档、目录说明等

## 语义约定

- `pilot_10`：仅用于早期流程验证、问题定位和 prompt 调整，不作为最终结论依据。
- `v2604_100`：正式实验数据与结果，后续报告、对比与结论统一以此为准。
- `preparation`：用于保存样本池、匹配过程和其他数据准备阶段文件，不与正式实验结果混放。

## 当前建议

- 上传 GitHub 时，优先保留 `scripts/`、`prompts/`、`results/v2604_100/`、`docs/`、以及样本清单类文件。
- 若仓库需要控制体积，可只保留 `pilot_10` 和 `v2604_100` 中的 manifest / pairs / reports，不直接提交全部原始 PDF、图片和 CIFP。

## 文档分工

- `docs/实验方案.md`
  - 当前正式实验的总方案说明，采用最新编号口径 `A/B/C/D/E/O`
- `docs/目录说明.md`
  - 当前项目目录组织说明
- `results/v2604_100/final_report_100.md`
  - 100 样本正式实验结果总结
- `results/v2604_100/path_C_experiment_design.md`
  - 新路径 C 的设计阶段记录，属于历史设计文档
